  BHARAT YATRA  —  QUICK START
  ( demo-day checklist + QR instructions:  DEMO-DAY.md )
  Smart India Hackathon · Tourism, Heritage & Culture
======================================================================

REQUIREMENT:  JDK 11 or newer.  Nothing else. No Maven download needed,
              no Spring, no npm, no database.


----------------------------------------------------------------------
 1.  OPEN IN INTELLIJ IDEA
----------------------------------------------------------------------
   a) Unzip this folder somewhere simple, e.g.  C:\SIH\bharat-yatra
   b) IntelliJ  ->  File  ->  Open...
   c) Select the folder  bharat-yatra   (the one containing this file)
   d) If IntelliJ asks "Maven project detected / Load Maven Project?"
         -> click LOAD.   (optional, but it sets everything up for you)
      If it does NOT ask:
         -> right-click the folder  src/main/java
         -> Mark Directory as  ->  Sources Root


----------------------------------------------------------------------
 2.  RUN IT
----------------------------------------------------------------------
   Open:   src/main/java/in/bharatyatra/App.java
   Click the green ▶ arrow next to  "public static void main"

   The console prints:

        ####  BHARAT YATRA  ####
        Running at    : http://localhost:8080
        On your phone : http://192.168.x.x:8080   (same Wi-Fi)

   Open  http://localhost:8080  in Chrome.


----------------------------------------------------------------------
 3.  DEMO ON THE JUDGES' PHONES
----------------------------------------------------------------------
   Put their phone on the same Wi-Fi as your laptop, click the  ▦
   button in the app header -> a QR code appears -> they scan it.
   Anything they add from their phone shows up on your screen instantly.

   (If it doesn't open on the phone, allow Java through the Windows
    Firewall, or use a mobile hotspot from your own phone.)


----------------------------------------------------------------------
 4.  WITHOUT INTELLIJ  (terminal)
----------------------------------------------------------------------
   Windows :  run.bat
   Mac/Linux: ./run.sh

----------------------------------------------------------------------
 6.  TROUBLESHOOTING
----------------------------------------------------------------------
   "Port 8080 already in use"
        -> run App with a different port:
           Run -> Edit Configurations -> Program arguments:  8081

   "Not found: /index.html"  or a blank page
        -> Run -> Edit Configurations -> Working directory
           must be the project root (the folder with src, data, tools)

   The 3D map doesn't appear
        -> the browser has no WebGL. Use Chrome/Edge, and in
           chrome://settings/system turn ON hardware acceleration.
           (The app still works: use Explore -> pick a state.)

   Photos missing, illustrations showing instead
        -> that's by design when offline. See HOW-TO-ADD-PHOTOS.md.
